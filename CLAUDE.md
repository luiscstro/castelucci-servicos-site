# CLAUDE.md

Instruções de processo para este repositório estão em [AGENTS.md](AGENTS.md) — leia esse
arquivo antes de iniciar qualquer tarefa de código. Resumindo: toda correção, melhoria ou
funcionalidade nova passa por Issue no GitHub → branch → Pull Request mencionando a Issue
(`Closes #N`) na descrição. Não commitar direto em `main`, não dar push/merge sem confirmação
do usuário.

AGENTS.md também define o padrão obrigatório de interface (skeleton loading, lazy loading,
scroll reveal, progresso em ações assíncronas, `prefers-reduced-motion`) que toda página ou
componente novo precisa seguir — não pule essa seção.
